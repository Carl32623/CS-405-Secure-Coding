# CS-405 Secure Coding

This repository contains coursework and projects completed for a Secure Coding course focused on developing safe, reliable, and secure C++ applications. The work emphasizes identifying vulnerabilities, applying defensive programming techniques, and following industry-recognized security standards.

## Repository Structure

- **Coding-Problems/**
  - Collection of C++ exercises and coding activities
  - Focus areas include input validation, buffer overflow prevention, exception handling, and general secure coding practices

- **Security-Policy/**
  - Formal security policy document developed as part of course requirements
  - Outlines principles, standards, and best practices aligned with secure software development

- **Security-Presentation/**
  - Presentation materials covering secure development concepts
  - Includes topics such as threat mitigation, secure design strategies, and real-world security considerations

## Key Concepts Covered

- Input validation and sanitization  
- Buffer overflow prevention  
- Exception handling and error management  
- Secure memory usage  
- Static code analysis  
- Secure coding standards (SEI CERT C++)

## Technologies Used

- C++  
- Visual Studio  
- Static analysis tools (e.g., Cppcheck)  

## Purpose

The goal of this repository is to demonstrate an understanding of secure coding principles and the ability to apply them in practical programming scenarios. Each project and exercise reflects hands-on experience identifying and mitigating common software vulnerabilities.

## Notes

This repository is part of my academic work as a Computer Science student. The projects are designed to simulate real-world secure development practices and build a strong foundation in writing safe, maintainable code.
